# Asset and distribution notes

## Web assets

The images in `public/models/` and `public/training/` are optimized JPEG copies prepared for this comparison site. They are not the original training or evaluation files.

## Training references

The 58 training references were assembled from two working collections named LORA Photos and Swiss Poster Data Set 2. Some images reproduce or reference existing poster and design work. Their inclusion here documents the experiment; it does not imply ownership or grant reuse rights.

Before making this repository public, review whether each training reference may be redistributed. If that review is incomplete, keep the repository private or remove `public/training/` and retain only filenames, captions, and provenance records.

## Model outputs and weights

The repository contains optimized evaluation outputs but does not contain Krea model checkpoints or LoRA weights. Use of the underlying models and weights remains subject to their respective licenses and terms.

## Sensitive files

The repository intentionally excludes private keys, Hugging Face credentials, Prime Intellect credentials, environment files, local model caches, original full-resolution assets, and generated training checkpoints.
